# Ethical UI sketch

Experiments in making "I agree" slower on purpose, so people get a fair chance to notice what they're agreeing to.

- **Part 1 · Consent Obstacle Course**: five deliberately slow "I agree" controls (a terms line that reveals the fine print as you pass it, an 8-second hold, a ring you wind three times, a marble maze with opt-in traps, and a dot you drag from I to AGREE).
  https://kettykuutvuori.github.io/ethical-ui-sketch/
- **Part 2 · Roll to Agree**: a first-person 3D roll toward an AGREE gate. Hold to roll, let go and it rolls back; the key clauses appear over the road as you pass them.
  https://kettykuutvuori.github.io/ethical-ui-sketch/roll-to-agree/
